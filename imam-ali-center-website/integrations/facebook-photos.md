Selection is computed from the local calendar on the server and browser, so it requires no logged-in Facebook session, scheduler, or ongoing external fetch. An already-open homepage checks for a changed week once per minute and when visible again.

This rotates downloaded, reviewed photos. It does not automatically ingest newly published Facebook posts. The user explicitly chose this interim behavior on October 8, 2026.

To refresh the approved library, import genuine community crowd photographs from the IAC Facebook Page; omit announcement artwork and private-service scenes. Update dist/content.json slides and the browser fallback together, then publish. The existing owner editor can also change the ten-photo library without a rebuild.

Service photos are public celebration, Qur’an, or remembrance details; they do not identify anyone as a marriage, divorce, or funeral client.
